# Axonobox — issues

This is where to report bugs and ask questions about Axonobox, a Blender add-on for drawing in Edit Mode.

Please open an issue and include:
- your Blender version and operating system
- the Axonobox version (Edit › Preferences › Add-ons)
- what you did, what you expected, and what happened
- a screenshot or short screen recording if you can
